# System Breach: Love Detected 💖

A retro-style terminal animation that "crashes" into a beautiful Valentine's Day surprise.

## Features ✨

*   **Retro Terminal Interface**: Authentic typing animation with green-on-black aesthetics and the VT323 font.
*   **System Overload Sequence**: Simulates a "Love Detected" breach that overwhelms the system.
*   **Dark Room Spotlight**: After the crash, the screen goes pitch black. Use your mouse as a flashlight to find the hidden message.
*   **Interactive Reveal**: Click anywhere to trigger a blinding flash that reveals the full message and starts a shower of falling hearts.
*   **Custom Effects**:
    *   Heart-shaped cursor in "Dark Mode".
    *   Realistic yellow beam with floating dust particles.
    *   Smooth transitions and physics-based heart particles.

## How to Run 🚀

Simply open `index.html` in any modern web browser.

## Customization 🛠️

You can edit the `CONFIG` object in `index.html` to change:
*   `targetName`: The name of the person you are surprising.
*   `customMessage`: The main message displayed.
*   `bootLines`: The text sequence shown in the terminal.
*   `colors`: The color palette for the terminal and hearts.

## Technologies 💻

*   HTML5 Canvas
*   Vanilla JavaScript (No libraries required)
*   CSS3 Animations
